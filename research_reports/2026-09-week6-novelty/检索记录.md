## 3. 筛选流程（文字版 PRISMA）

```
识别（两轮网页+作者稿+专利+中文题录）
        │
        ├─ 与 OBS 竞争缓解、卫星光交换、FDL、L-OBS 明显无关 → 排除
        │     （RF 卫星、纯 MEMS OCS 器件、星地物理层帧、电存储转发交换机）
        │
        ├─ 摘要相关 → 全文或 HTML 摘录
        │     取得：Chen 2004、ChinaCom 2010、Zhao HTML、ADI HTML、
        │           L-OBS 2008/2010 PDF、Roethig/Mouammar PDF、Teng 2005 PDF
        │     未取得：Lee 2006、Qiao 2000、中文期刊原文、多数 2023–2026 地面刊、专利全文
        │
        └─ 纳入决策对照
              核心近邻：Zhao 2022、L-OBS、ChinaCom、Chen 2004、ADI 2025、Roethig/Mouammar
              2023–2026 / 中文 / 专利：写入相关工作，不改变「组合缺口仍在」
              降权：Naji 2023；Lee 2025 AI-FDL
              移出必写：Lee 2006、Qiao 2000（未读原文）
```

**排除理由（可复述给评审）：**

1. 只做地面多波长 + 波长变换的 FDL 定维 → 作为经典背景，不当「本文已有」。
2. 在线模糊 / AI 定 FDL → 触碰星载算力红线。
3. 电缓存填空隙的边缘/核心联合（Lee 2006）→ 手段不同；且未读原文，不进必写。
4. 专利只做 OBS/OFS 接入选择或光电混合交换 → 不覆盖 τ/T_burst 回环窗。
5. 星载电交换机 FPGA 实现 → 不是光突发。

## 4. 对 Go 决策的影响（补扫后）

补扫**没有**找到同时满足下面全部条件的已发表工作：

- 星间 / 卫星；
- W=1；
- 载荷可实现的**单级单次回环** FDL；
- 以 τ/T_burst 报告工作区间；
- 与专利边缘四模式做 2×2。

因此 2026-09-11 的 **有条件 Go、主叙事收缩** 维持。补扫的价值是：相关工作必须写 2023–2026 地面 FDL、CN108809719A、中文星载 OBS 调度/组装，不能再假装「近年没人做 OBS」。

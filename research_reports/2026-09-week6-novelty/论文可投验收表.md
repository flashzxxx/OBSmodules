> Paper · 2026-09-11；2026-09-14 同步书目，并按 [`论文骨架.md`](论文骨架.md) 重列门槛。  
> 用途：定义「做到什么程度才有资格试投」；**不是**「做到就能中」。  
> 口径：继续实验；当前档位仍是 **A 不可投**。

## 档位定义

| 档位 | 含义 | 客观条件 |
|------|------|----------|
| **A. 不可投** | 只有平台/功能通路 | 未过回环确定性用例；或仅有标定/`useFDL=false`；或只有「FDL 能跑通」；或无重传基线 |
| **B. 勉强可投会议短文/国内一般刊（低把握）** | 有对照增量，故事窄 | 满足下方 **M1–M4 + M7 + M8 + 必备图 1–6 与表 1–2** |
| **C. 可投中等期刊/较好会议（中低把握）** | 增量稳定且对标完整 | 满足 **B + M5**（敏感性：突发长度 / 10 Gbps / 热点）+ 对标段写死近邻差异（含排队论上界） |
| **D. 若主张 offset/控制时序** | **第二篇**，不进第一篇 | **必须另有 M6（输入 FDL 时序）**；仅回环数据 → **自动降回 A/B，且不得写全光控制闭环** |

**裁决规则**：缺任何一条「否决项」→ 停在 A，不讨论投稿。达到 B 只表示「可以准备投稿材料试一试」，审稿仍可能按「OBS+FDL 已有」或「单级 FDL 排队论已知」拒。

---

## 否决项（任一成立 → 不可投）

- [ ] 回环确定性用例未过（冲突→进 FDL→`+τ` 再出；BCP 偏移含 τ；Horizon 不崩）  
- [ ] 用 `useFDL=false` 标定数据当作回环性能结论  
- [ ] 无 No-FDL 对照，或只展示「某一组好看参数」  
- [ ] **无重传基线**（只有冲突即丢、不重传的稻草人）  
- [ ] 相关工作无法说明相对 Chen / Zhao / Legrand **以及 FDL 排队论上界**多出来的是什么  
- [ ] 正文主张「严格全光控制 / offset=0 已验证」但无输入 FDL 时序证据  
- [ ] 声称首次 OBS+FDL，或首次卫星/W=1 OBS  

实验 B 的 2×2 不再作为否决项：它回答的是「交叉点是否移动」，负结果也可以写。未做 2×2 则第一篇缺 5.4 节，档位不超过 B。

## 必达项（M1–M8）

| ID | 项 | 通过标准（客观） |
|----|----|------------------|
| **M1** | 回环确定性用例 | 阿sir按既定标准认过；有 EV/`.sca` 可复核；全节点 `oxcBurstDropped == 0` |
| **M2** | 实验 A · τ 工作区间 | W=1；**3 档负载 × Horizon/VF**；τ 扫描给出有效区 / 无增益区 / 边界；与 No-FDL 对照；主指标含丢包及 FDL 使用/拒绝分解。第三档 ρ=0.8 须来自热点矩阵的实测，不得把全互联 21.3 µs（约 0.59）标成 0.8 |
| **M3** | 实验 B · 2×2 | 四格：边缘开/关 × FDL 开/关；只回答**联合是否移动 5.2 交叉点**；跨种子稳定；须报告 burst 长度公平性 |
| **M4** | 对标段落 | 明文：vs 排队论上界（多波长/无器件代价）、vs Chen（可选 FDL）、vs Zhao（分布式调度≠载荷 FDL；HTML 摘录）、vs Legrand（输入 FDL≠回环） |
| **M5** |（冲 C 档）敏感性 | 突发长度、`FDL-RateCheck`、热点流量至少两类；结论不随单一点翻转 |
| **M6** |（仅第二篇）输入 FDL | 独立时序模型或实验：边缘 offset=0 所需 τ_in 下界；与回环数据分开呈现。**移出本文** |
| **M7** | 重传基线对照 | `ExpR-Retransmit`：host 侧重传已实现；goodput/时延/丢包与回环叠图；找得到交叉点或能证明全程一侧占优。配置占位而模块未实现 → 本项未过 |
| **M8** | 载荷可行性图 | 把 D1（或 2026-09-28 默认开关表）的可行 τ 区间叠到 M2 曲线上，得到有用 / 无增益 / 物理不可行三区 |
